# to-do-list
This is a simple To-Do List web application built as a practice exercise using TypeScript/JavaScript, HTML, and Custom Elements (Web Components).

The goal of this project is to explore and better understand how to create reusable and modular components using native browser APIs, without relying on external frameworks.

Technologies Used
- TypeScript / JavaScript

- HTML

- Web Components (Custom Elements, Shadow DOM)

Purpose
This is a learning project, aimed at reinforcing:

- The use of custom HTML elements.

- DOM manipulation using modern web standards.

- Clean, modular code with separation of concerns.
